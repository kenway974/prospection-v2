# Lot 0 · Socle — plan de construction

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** une app web protégée par mot de passe, installable sur Android, avec sa coquille mobile (navigation flottante, 4 écrans vides), déployable sur Railway, et toute la chaîne qualité (lint, types, couches, tests, audit, image, bout en bout) bloquante en CI.

**Architecture :** paquet `src/prospection/` découpé en couches `domain / sources / crm / storage / application / ui` (contrat import-linter). FastAPI rend des pages Jinja2 côté serveur ; HTMX est servi en fichier statique ; PostgreSQL via SQLAlchemy Core + Alembic. Pas encore de worker (arrive au lot 2).

**Tech Stack :** Python 3.13, uv, FastAPI, Jinja2, HTMX 2, SQLAlchemy 2 Core, Alembic, psycopg 3, argon2-cffi, itsdangerous, pydantic-settings, pytest, pytest-cov, Playwright (Python), ruff, mypy, import-linter, pip-audit, Docker, GitHub Actions, Railway.

**Spec :** `docs/superpowers/specs/2026-10-24-prospection-v2-design.md` (sections 4, 5, 7). Feuille de route : `docs/superpowers/plans/2026-10-24-feuille-de-route.md`.

## Global Constraints

- Python **3.13** (la spec disait 3.12 ; 3.13 est la version disponible et supportée, corrigé dans la spec).
- Code (noms de modules, fonctions, variables) en **anglais** ; **tous les textes visibles en français**, phrases courtes, messages d'erreur qui disent quoi faire.
- Fichiers Python de `src/` : **150 lignes maximum** (vérifié par `scripts/check_file_size.py`, bloquant en CI).
- `mypy --strict` sans erreur ; `ruff check` et `ruff format --check` sans erreur ; `lint-imports` vert.
- Couverture : **≥ 90 %** sur `src/prospection/domain/`, **≥ 80 %** global.
- Tests rejoués avec `TZ=America/Los_Angeles`. **Aucun réseau** dans les tests (sauf la base PostgreSQL locale de test).
- Le domaine ne lit jamais l'horloge : `now: datetime` (aware, UTC) est passé en paramètre.
- Chaque test cite son comportement (`C01`…) dans son nom ou sa docstring ; un commit par comportement, message en français « avant / après », avec les lignes d'attribution de la session.
- Gabarits Jinja2 en échappement automatique ; aucun `|safe` sur une donnée.
- CSP sans script ni style en ligne (HTMX configuré avec `includeIndicatorStyles: false`).
- Dépendances verrouillées dans `uv.lock` (commité) ; versions épinglées ; HTMX **2.0.x** vendu dans `static/` avec sa version dans le nom du fichier.
- Style : celui des maquettes validées (https://claude.ai/artifact/MxncTwxekn6dHL9i18YZ9o) : police système, fond `#F2F2F7`, texte `#1C1C1E`, secondaire `#6C6C70`, bleu océan `#1A3E8F`, jaune `#FFC400`, rouge volcan `#D62718`, cibles tactiles ≥ 44 px, barre de navigation flottante sur une ligne.

## Review Focus

1. **Mot de passe faux répété depuis une autre IP** : le blocage (C82) compte tous les échecs récents, quelle que soit l'IP (un seul utilisateur). → test dans la Task 4.
2. **Cookie de session expiré, falsifié, ou d'avant un changement de mot de passe** : redirection vers `/connexion`, jamais d'erreur 500. → test dans la Task 6.
3. **Requête POST venue d'un autre site (CSRF)** : refusée (403) même avec un cookie valide. → test dans la Task 5.
4. **Requête HTTP en clair derrière le proxy Railway** : redirigée en HTTPS (308), sauf `/sante` (sonde de Railway). → test dans la Task 5.
5. **Base injoignable au démarrage ou pendant une connexion** : page d'erreur française qui dit quoi faire, pas de trace Python affichée. → test dans la Task 6.

**Files :**
- Create : `src/prospection/domain/login_throttle.py`

**Interfaces :**
- Produces : constantes `MAX_FAILURES = 5`, `WINDOW = timedelta(minutes=15)`, `LOCKOUT = timedelta(minutes=15)` ; `dataclass(frozen=True) Throttle(allowed: bool, retry_after: timedelta)` ; `check_login_allowed(failures: Sequence[datetime], now: datetime) -> Throttle`.
